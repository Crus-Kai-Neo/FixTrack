# FixTrack Database (`FixTrackDB`) – SQL Server (SSMS)

## Folder Structure
- `01_setup/` – Database creation and API SQL login setup
- `02_schema/` – Tables, Primary Keys, Foreign Keys, CHECK constraints, and indexes
- `03_programmability/` – SQL Views and Stored Procedures for Express.js endpoints
- `04_seed_data/` – Realistic sample data for testing all 13 UI screens
- `05_reset_and_maintenance/` – Reset and verification scripts
- `docs/` – ERD diagram, Data Dictionary, and Node.js connection guide
